# AED N@VI 設置情報（岡山県）

`npm run data:aed-navi` は Node.js から AED N@VI の岡山県に重なる6つの配信区画を取得します。配信CDNは圧縮要求の有無で応答が異なるため、`Accept-Encoding: gzip` を明示します。既存の市町村境界で岡山県内を抽出し、`data/okayama.json` を更新します。施設名・住所は公式の詳細取得先からまとめて取得し、取得できない場合は既存値またはID表示を使います。

施設名、利用条件、設置画像のURLなどの詳細は前回の取得から24時間が経った施設だけ更新します。画像本体は保存せず、プロパティを開いたときに公式の公開画像を読み込みます。掲載画像がない施設では画像欄を表示しません。

`/api/aed-navi-data` は Node.js の `fetch` で公式公開データを直接取得します。成功応答は Vercel CDN と同じ Function インスタンス内で2分間共有します。更新番号が同じなら配信区画を再取得せず、番号だけ確認します。レイヤーは表示中に2分ごとに確認します。直取得に失敗した場合は保存済みスナップショットへ切り替え、操作画面に警告を表示します。失敗応答はCDNに保存しません。

`.github/workflows/aed-navi-update.yml` は30分ごとにスナップショットを更新します。県内IDの追加・削除、施設名・住所の補充、直取得が使えない環境での予備データとして必要です。GitHub Actions の書き込み権限と、更新コミットからのデプロイが有効であることが必要です。公開中のデータ取得日時はレイヤーの操作画面に表示されます。

利用時間の色分けは、公開データにある通常の曜日・時間帯を日本時間で判定した目安です。祝日、臨時休業、現地のAEDの状態は確認できません。配信元の更新時刻や機器の稼働状態を示すものとして扱わないでください。
