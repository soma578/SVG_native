# 非常用電源・ムービングハウスの手動登録

「岡山大学」グループにある2つのレイヤーは、現時点では公開JSONを手動更新する。現在はアイコンとUIを確認するための**架空のデモデータ各8件**を岡山県内の複数地域に分散している。実在設備・実際の利用可否ではない。レイヤー名、コントローラー、詳細表示にも「デモ」を明記した。

- 非常用電源: `svgmapAppLayers/appLayers/emergencyAssets/battery.json`
- ムービングハウス: `svgmapAppLayers/appLayers/emergencyAssets/movingHouse.json`

ファイルを変更してデプロイすると反映される。コントローラーの「データを再取得」で再読込できる。公開情報なので個人名・連絡先・非公開の設備位置を入れない。最終確認日時が古い値は現在の利用可否を保証しないため、運用時は更新担当と更新間隔を決める。実データに移行するときはデモ行を全件削除し、`"demo": false` に変更してからレイヤー名の「（デモ）」も外す。

デモの方向性は[安信工業の蓄電池・再エネ事業](https://yasunobu-co-ltd.com/business.html)と、[ウッディワールドのざきのムービングハウス案内](https://www.wwn.co.jp/new/movinghouse-toiawase)を確認した。前者は固体電池とオフグリッド化、後者は住居・長屋敷住居・寄宿舎などの型を案内している。ウッディワールドのざきはトレーラーハウスとは異なると説明しているため、地図アイコンも車輪なしの連結住戸型とした。**両社の公開ページに各設置地点の容量・残量・定員・入居人数は掲載されていないため、デモの所在地と数値はすべて仮値**。個々のピンは両社の製品や設置実績を示さない。

## 非常用電源

```json
{
  "updatedAt": "2026-10-14T10:30:00+09:00",
  "demo": false,
  "assets": [
    {
      "id": "BAT-001",
      "name": "非常用電源 A",
      "address": "岡山市北区（公開可能な住所）",
      "lat": 34.655,
      "lng": 133.92,
      "status": "available",
      "chargePercent": 75,
      "capacityKWh": 10,
      "updatedAt": "2026-10-14T10:30:00+09:00"
    }
  ]
}
```

これは形式例であり、実在設備を示さない。`status` は `available`（使用可能）、`inUse`（使用中）、`fault`（故障・利用不可）、`unknown`。残量・容量が未確認なら `null`。残り電力量は「定格容量 × 残量率」の概算で、実際の利用可能量や稼働時間を保証しない。

## ムービングハウス

```json
{
  "updatedAt": "2026-10-14T10:30:00+09:00",
  "demo": false,
  "assets": [
    {
      "id": "MH-001",
      "name": "ムービングハウス A",
      "address": "倉敷市（公開可能な住所）",
      "lat": 34.585,
      "lng": 133.77,
      "placement": "installed",
      "accepting": true,
      "capacity": 4,
      "occupied": 2,
      "updatedAt": "2026-10-14T10:30:00+09:00"
    }
  ]
}
```

これも形式例。`placement` は `inTransit`、`installing`、`installed`、`unknown`。`accepting` は受付中なら `true`、停止なら `false`、未確認なら `null`。人数が未確認なら `null`。入居者の氏名など個人情報は登録しない。空き人数は定員と入居人数から算出し、受付可否とは別に表示する。

両ファイルとも `id` はレイヤー内で一意、緯度・経度と各設備の `updatedAt` は必須。`address` は省略可能。値が不正な場合は古い表示を残して読み込みエラーを示し、誤ったピンを増やさない。将来API化するときも、この公開JSONと同じ応答構造を維持すれば地図側の変更を小さくできる。
