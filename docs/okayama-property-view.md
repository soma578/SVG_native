# 岡山大学レイヤーのプロパティ表示

現在は、岡山大学グループのレイヤーで個別の詳細カード登録を抑制し、SVGMapの `property` / `content` メタデータをホストの安全な表形式で表示します。地図の描画、データ取得先、コントローラーは切り替えません。画面上に切替ボタンはありません。

元の独自詳細カードに戻す場合は、`public/okayama-property-view.js` の `OKAYAMA_PROPERTY_VIEW` を `'custom'` に変更して再デプロイしてください。元の詳細表示関数は削除していません。対象は `Container.svg` で `岡山大学` クラスを持つレイヤーです。他の本家レイヤーの表示登録は変更しません。

表形式では動画・画像の操作やレイヤー固有の追加ボタンは表示されません。MOSAdemyは施設1ピンを維持し、公開された数値とカメラURLを表の項目として表示します。カメラ操作などの独自UIが必要になった場合は上記設定で戻せます。
