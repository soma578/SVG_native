# 岡山大学レイヤーのプロパティ表示

現在は、岡山大学グループのレイヤーで個別の詳細カード登録を抑制し、SVGMapの `property` / `content` メタデータをホストの表形式で表示します。レイヤー側でも登録を抑制するため、外部ホストからクロスオリジンの S-LaWA として読み込まれても同じ方式です。地図の描画、データ取得先、コントローラーは切り替えません。画面上に切替ボタンはありません。

元の独自詳細カードに戻す場合は、`public/okayama-property-view.js` の `OKAYAMA_PROPERTY_VIEW` を `'custom'` に変更して再デプロイしてください。元の詳細表示関数は削除していません。対象は `Container.svg` で `岡山大学` クラスを持つレイヤーです。他の本家レイヤーの表示登録は変更しません。外部ホストで使う場合は、同じデプロイのレイヤー SVG・HTML・JavaScript を読み直してください。

岡山大学レイヤーの標準 `property` / `content` には出典を含めます。こちらのホストの `customShowPoiProperty.js` は、このグループの `title/Layer` にレイヤー名だけを表示し、施設名や杭IDなどは個別のメタデータ列と重なり候補一覧に残します。外部ホストがSVGMap本体の既定プロパティ関数だけを使う場合、同関数はPOIタイトルとレイヤー名を `title/Layer` で連結するため、同じ見た目にするには外部ホスト側にも表示規則の設定が必要です。

表形式でも画像URLの項目はプレビューします。Google Sheet由来の署名付き `/api/private-sheet-image` URL、MOSAdemyの公開カメラ画像、全国河川監視カメラの現在画像に対応しています。河川カメラは配信元が直接取得に403を返すため、固定配信元だけを許可する `/api/river-camera-image` を通します。取得に失敗した画像はリンクを残してエラーを表示します。ただし動画操作やレイヤー固有の追加ボタンは表示されません。MOSAdemyは施設1ピンを維持します。カメラ操作などの独自UIが必要になった場合は上記設定で戻せます。
