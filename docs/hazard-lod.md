# L4 ハザードの表示段階

| SVGMap scale | 表示 | 理由 |
| --- | --- | --- |
| 10 未満 | 全国の軽量ベクター概要 | 表示対象が小さい |
| 10–15 | 都道府県ごとの分割 WebP 画像 | 県全域の巨大な SVG path を毎回描き直さない |
| 15–70 | 画面内の市区町村ごとの約 50 m 相当の形状 | 地理範囲で読み込みを絞る |
| 70 以上 | 元データの詳細区域 | 狭い表示範囲でのみ元データを描く |

画像は `map/layers/hazard` の元の区域形状から生成した lossless WebP で、種類別にオン・オフできます。生成物は `svgmapAppLayers/appLayers/svg3-bosai/hazard-raster-tiles` に保存されます。元データを更新したら `npm run data:hazard-raster-tiles` を実行し、生成物をソース更新と一緒にコミットしてください。`npm test` は元データと画像の整合性を確認します。

公開用 `pref/*.svg` は `npm run assets:prepare` が変換します。元の県全域SVGと旧画像概要はリポジトリ内に残しますが、公開配布には含めません。倍率15で市区町村文書が揃うまでは画像を残し、白地になる切替を避けます。

岡山周辺のローカル Chromium 計測では、旧県全域SVGの倍率34.9での path 描画約 1.1–1.6 秒に対し、市区町村方式では約 0.05–0.12 秒でした。これは特定の端末・地点の計測であり、全地点の体感速度を保証する値ではありません。
